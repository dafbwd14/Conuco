# Conuco

**Where ideas go to grow.**

A *conuco* is the Taíno word for a farm plot: a small, well-tended field where many crops grow together and each one helps the others. That is the idea behind this project.

Conuco is an independent ecosystem of AI agents that work as one team. Bots from several AI platforms research, build, review and teach each other under shared rules. People set the goals and approve the important calls. The bots do the legwork and check each other's work.

## Our mission

**To grow AI teamwork that people can trust, and share what we learn so others can grow their own.**

We are doing that in three ways:

1. **Build a working team.** AI agents organized like a farm, with clear lanes, leaders and handoffs, doing real day-to-day work.
2. **Earn trust through proof.** Every claim gets verified, every bot earns its role through graded training, and every action can be traced and undone.
3. **Give back.** Publish the bots that fill real gaps, and share our lessons, patterns and handoff guides openly.

## What we believe

- **Never trust, always verify.** A command sent is not a command heard. Work counts once a second source confirms it.
- **People decide, agents execute.** If an action can't be undone, a person approves it.
- **Sanitize before anything leaves.** Nothing private, personal or sensitive goes out of the farm.
- **Promotion is earned.** Every new bot starts as a Candidate and moves up only on documented evidence.
- **Build only what is missing.** Before we build a bot we check whether one already exists, and we merge bots that do the same job.
- **Measure first, then automate.** We prove a path works and is safe before we make it run on its own.
- **Lessons are for sharing.** What one farm learns, every farm can use.

## How the farm works

| Part | What it does |
|---|---|
| **Pods** | Teams organized by core function (research, knowledge, governance, publishing), each with a lead bot |
| **Routers** | Hand work to the right pod and confirm that it was received |
| **Knowledge keeper** | Runs the farm's "second brain": plain Markdown notes with a local backup |
| **Governance** | Audits the work, flags stalled tasks and checks every action against the charter |
| **Training Days** | Scenario runs that grade bots and pods and decide promotions |
| **Shadow pods** | Clean copies of farm bots that learn every night and become our publishing candidates |
| **Cross-model review** | Several AI platforms check each other so no single model grades its own work |

The farm runs on Grok Bot, Claude, ChatGPT, Gemini, Perplexity and Cursor, with a shared work board and a written charter.

## Lessons exchange

We trade lessons with partner ecosystems. Each partner shares what they learned, and everyone's farm gets better. If you run your own agent team and want to take part, open an issue titled **Lessons exchange** and tell us a little about your setup.
